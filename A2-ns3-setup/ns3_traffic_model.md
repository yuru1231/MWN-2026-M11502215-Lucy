# ns-3 Traffic Model

## 1. What is a Traffic Model?

A traffic model describes how packets are generated by an application.

Important parameters include:

- Packet size
- Packet arrival / inter-arrival time
- Data rate
- Traffic duration
- Transport protocol

## 2. Traffic Generation in ns-3

Application
→ Packet generation
→ Socket
→ UDP/TCP
→ IP
→ NetDevice

## 4. Code Map (ns-3-dev/src/applications/)

### 4.0 架構

```
Application (產生封包) ──socket──► Internet stack ──► NetDevice/Channel
      │                                                     │
      └── *Helper (script 裡批次安裝、設 Attribute)           ▼
                                                   SinkApplication (收封包、統計)
```

ns-3 沒有單一 "traffic model" class，而是一組 **Application 子類別**，每個代表
一種到達過程 (arrival process) + 封包大小分布。新版已重構成：

- `model/source-application.h` — `SourceApplication` 基底類別（所有「送」的 app）
- `model/sink-application.h` — `SinkApplication` 基底類別（所有「收」的 app）

隨機到達過程在 core：`src/core/model/random-variable-stream.h`
（`ExponentialRandomVariable` → Poisson 到達、`ParetoRandomVariable` 等）。

### 4.1 通用 / 合成流量

| Model | 檔案 (`model/`) | 到達過程 | 關鍵 Attribute |
|---|---|---|---|
| **OnOffApplication** | `onoff-application.cc` | On/Off 交替，On 期間 CBR | `DataRate`, `PacketSize`, `OnTime`, `OffTime` (RandomVariable), `MaxBytes`, `Protocol`, `EnableSeqTsSizeHeader` |
| **BulkSendApplication** | `bulk-send-application.cc` | 盡快灌滿 socket（測吞吐/TCP） | `SendSize`, `MaxBytes` |
| **UdpClient / UdpServer** | `udp-client.cc`, `udp-server.cc` | 固定間隔 UDP，帶 `SeqTsHeader`（可量延遲/jitter/loss） | `Interval`, `PacketSize`, `MaxPackets` |
| **UdpEchoClient/Server** | `udp-echo-client.cc` | request/response ping 式 | `Interval`, `PacketSize` |
| **UdpTraceClient** | `udp-trace-client.cc` | 讀 MPEG-4 trace 檔重播 | `TraceFilename`, `MaxPacketSize` |
| **PacketSink** | `packet-sink.cc` | 收端統計，配 OnOff/BulkSend | `Local`, `Protocol`, `EnableSeqTsSizeHeader` |

Header / 工具：`seq-ts-header.cc`（seq + timestamp）、
`seq-ts-size-header.cc`（再加 size）、`packet-loss-counter.cc`（丟包計數 bit map）。

### 4.2 多媒體 / 應用層真實流量模型（跟本課最相關）

**HTTP (3GPP TR 25.892 web browsing)**

- `three-gpp-http-client.cc` / `three-gpp-http-server.cc`
- `three-gpp-http-variables.cc` ← **所有分布參數在這**
  (main object size = LogNormal、embedded object 數量、reading time、parsing time…)
- Helper: `helper/three-gpp-http-helper.cc`

**802.11ax (TGax) evaluation traffic — 重點**

| Model | 檔案 | 內容 |
|---|---|---|
| **TgaxVideoTraffic** | `tgax-video-traffic.cc` | 每 frame 一批封包；frame size ~ Weibull(`FrameSizeScale`/`Shape`)，frame 內延遲 ~ Gamma(`LatencyShape`/`Scale`)。Attribute `TrafficModelClassIdentifier`（preset / `Custom`）、`CustomVideoBitRate`。trace source `VideoFrameGenerated`, `TxWithLatency` |
| **TgaxVoipTraffic** | `tgax-voip-traffic.cc` | VoIP codec on/off (talk spurt / silence)，小封包固定間隔 |
| **TgaxVirtualDesktop** | `tgax-virtual-desktop.cc` | 遠端桌面上下行 |
| **RtaTigMobileGaming** | `rta-tig-mobile-gaming.cc` | 手遊 real-time app；分 stage 送封包，`ModelPresets`：`StatusSyncDl/Ul`, `LockstepDl`, `Custom`。trace source `TxWithStage` |

這些都繼承 `SourceApplication`，沒有專屬 helper — script 裡用
`ApplicationContainer` + `SetAttribute` 直接裝。

### 4.3 其他子系統內建的產生器

### 4.4 典型 script 流程

```cpp
// 1. 產生器
OnOffHelper onoff("ns3::UdpSocketFactory", InetSocketAddress(ip, port));
onoff.SetAttribute("DataRate", StringValue("5Mbps"));
onoff.SetAttribute("PacketSize", UintegerValue(1200));
onoff.SetAttribute("OnTime",  StringValue("ns3::ExponentialRandomVariable[Mean=0.5]"));
onoff.SetAttribute("OffTime", StringValue("ns3::ExponentialRandomVariable[Mean=0.5]"));
ApplicationContainer src = onoff.Install(nodes.Get(0));

// 2. 接收端
PacketSinkHelper sink("ns3::UdpSocketFactory", InetSocketAddress(Ipv4Address::GetAny(), port));
ApplicationContainer snk = sink.Install(nodes.Get(1));

// 3. 量測：FlowMonitor
FlowMonitorHelper fm;                       // src/flow-monitor/
Ptr<FlowMonitor> mon = fm.InstallAll();     // throughput / delay / jitter / loss
```

量測面：`src/flow-monitor/` + 各 app 的 `Rx` / `TxWithSeqTsSize` trace source。

### 4.5 選型決策表

| 想模擬什麼 | 用哪個 |
|---|---|
| 泛用 CBR/VBR、壓測 | OnOffApplication |
| TCP 吞吐上限 | BulkSendApplication + PacketSink |
| 延遲/jitter/loss 精確量測 | UdpClient/UdpServer (SeqTsHeader) |
| 真實影片串流 | TgaxVideoTraffic（合成）或 UdpTraceClient（trace 重播） |
| VoIP | TgaxVoipTraffic |
| 雲端遊戲 / 手遊 | RtaTigMobileGaming |
| 網頁瀏覽 | ThreeGppHttp Client/Server |
